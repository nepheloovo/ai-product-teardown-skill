# AI产品拆解 Skill（ai-product-teardown）

按 OiiOii 级完整架构取证、分层拆解一款 AI 产品（尤其 Agent / Multi-Agent），输出飞书 / Markdown / HTML 报告，并单列【待核实】二次验证清单。

## 安装

把本仓库的 `SKILL.md` 放到 Agent 的 skills / workflows 目录即可（文件夹名建议 `ai-product-teardown`）。

## 何时用

- 拆解 / 复盘 / 面试准备某款 AI 产品
- 需要架构图、人机分工、模型成本、壁垒判断
- 需要按「已确认 / 待核实」做证据纪律

## 交付下限

默认交付物覆盖：一句话定位、效果评测、定位与差异、用户旅程、人机分工、技术形态、Multi-Agent 逐个拆解（若适用）、模型与成本、壁垒、分层架构总结、待核实清单。架构深度不低于飞书《以 OiiOii 为例拆解 Multi Agent 平台》。
